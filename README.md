# Calculadora Hello Kitty

Projeto de estudo de uma calculadora básica com tema da Hello Kitty, feita com HTML, CSS e JavaScript. A calculadora realiza operações simples e foi personalizada com cores, imagem e estilo fofos.

> ⚠️ **Aviso de autoria**  
> Este projeto foi desenvolvido como prática de front-end, com base em tutoriais, exemplos da internet e ajuda de IA, adaptando o layout e o código para o tema Hello Kitty. O foco é aprendizado, não uma aplicação complexa ou pronta para produção.

## Funcionalidades

- Realiza operações matemáticas básicas (adição, subtração, multiplicação e divisão).
- Interface visual personalizada com imagem da Hello Kitty.
- Atualização do visor da calculadora conforme o usuário clica nos botões.

## Tecnologias utilizadas

- **HTML:** estrutura da página (`index.html`).
- **CSS:** estilização da calculadora e do tema Hello Kitty (`style.css`).
- **JavaScript:** lógica das operações e interação com os botões (`script.js`).

## Estrutura de arquivos

- `index.html` – marcação da calculadora (visor e botões).
- `style.css` – estilos, cores, fontes e posicionamento dos elementos.
- `script.js` – funções responsáveis por montar a expressão, calcular o resultado e limpar o visor.
- `hellokitty.png` – imagem usada na interface da calculadora.

## Como executar

1. Faça o download ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador (Chrome, Edge, Firefox, etc.).
3. Use os botões da calculadora para testar as operações.

## Objetivos de aprendizado

- Praticar a criação de interfaces com HTML e CSS.
- Treinar a manipulação do DOM e eventos de clique com JavaScript.
- Experimentar a personalização de um projeto de calculadora simples com um tema visual diferente (Hello Kitty).

## Limitações

- A calculadora foi feita para estudo; não trata todos os casos de erro possíveis e não segue todas as melhores práticas de arquitetura de front-end.
- Algumas partes do código foram inspiradas ou adaptadas de tutoriais públicos e explicações de IA, como ponto de partida para o aprendizado.
